# ft_linear_regression

A from-scratch linear-regression project that estimates a car's price from its mileage. It fits a two-parameter model with gradient descent in Python, with optional plotting and mean-squared-error evaluation.

## Model

~~~text
price = theta0 + theta1 × mileage
~~~

The training script reads mileage and price data, min-max normalizes both variables, fits the parameters with gradient descent, converts them back to the original units, and writes them to a CSV. The prediction script loads the saved model and estimates the price for mileage entered at the prompt.

## Requirements

- Python 3
- Python standard library for training, prediction, and evaluation
- Matplotlib for the optional graph: python3 -m pip install matplotlib

## Provide the training data

The code expects the dataset at mandatory/data.csv, but this file is not currently present in the repository. Add it there before training. The first row is treated as a header; each following row must contain numeric mileage and price values in its first two columns.

Example format:

~~~csv
mileage,price
240000,3650
139800,3800
~~~

These sample rows illustrate the format only. Use the dataset you intend to train on.

## Quick start

Run from the repository root after adding mandatory/data.csv:

~~~sh
python3 mandatory/train.py
python3 mandatory/predict.py
~~~

Training writes mandatory/thetas.csv. Prediction asks for mileage in kilometers and prints an estimated price. Train again after changing the data; prediction uses the saved parameters and does not train automatically.

## Optional tools

~~~sh
python3 -m pip install matplotlib
python3 bonus/plot.py
python3 bonus/evaluate.py
~~~

Both optional tools require a trained model at mandatory/thetas.csv. The reported MSE is calculated on the data used for training, so it is a training-set metric rather than a held-out evaluation.

## Implementation notes

- Training uses 10,000 gradient-descent iterations with a learning rate of 0.01.
- Input rows and saved parameters are checked for numeric, finite values.
- Prediction rejects negative or non-finite mileage.
- Training rejects datasets where all mileage values are identical because the slope cannot be denormalized in that case.

This project focuses on the mechanics of fitting and using a simple model; it does not use a machine-learning framework.
